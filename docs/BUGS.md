## Filing a bug

1. Append a row with the next `BUG-###`; include a concrete repro.
2. Set Severity + Status `Open`.
3. On fix: Status `Fixed`, name the FEAT/commit and date in the Fix column, and
   record it in `DEVELOPMENT_HISTORY.md`.
